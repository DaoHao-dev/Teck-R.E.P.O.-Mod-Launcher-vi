# Hướng dẫn sử dụng Teck

## Tải đúng file

Trong **Releases → Assets**, tải `Teck-PS1-VI-EN.exe`. File “Source code” do GitHub tạo chứa mã nguồn; để dùng launcher, chọn EXE.

## Cài bộ mod

1. Đóng game và mở Teck.
2. Bấm cổng **1 / THIẾT LẬP**.
3. Chọn thư mục game, nơi có `REPO.exe` và thư mục `REPO_Data`.
4. Chỉnh số người chơi từ 2–20; bật/tắt chia sẻ nâng cấp và đặt tỉ lệ từ 0–100%.
5. Bấm **RESET / CÀI MOD** rồi đợi thông báo hoàn tất.
6. Bấm **POWER / MỞ GAME** để mở game qua Steam.

## Các nút trên thân máy

| Điều khiển | Chức năng |
| --- | --- |
| POWER | Mở R.E.P.O. qua Steam |
| RESET | Cài/cập nhật bộ mod |
| OPEN | Đóng/mở nắp |
| Đĩa khi mở nắp | Tạm dừng/tiếp tục xoay |
| Cổng 1 | Thiết lập game, số người, chia sẻ nâng cấp và gỡ mod |
| Cổng 2 | Hướng dẫn |
| F4 / MOD, F5 / XU | Mở hướng dẫn menu tương ứng |
| −, × | Thu nhỏ, đóng launcher |

Kéo vùng trống trên thân máy để di chuyển launcher.

## Menu trong game và ngôn ngữ

- **F4:** GameTools.
- **F5:** CosmeticsTools, quản lý trang trí và xu trang trí.
- **VI / EN:** đổi giữa tiếng Việt và tiếng Anh trong hai menu mod; lựa chọn được lưu.

Nếu một phím trùng với mod khác, kiểm tra phần thiết lập phím tắt. Các nút F4/F5 trên launcher hiển thị hướng dẫn; nhấn phím trong game để mở menu.

## Cập nhật và gỡ mod

**Cập nhật:** đóng game, chạy EXE mới và bấm RESET / CÀI MOD. Mở lại game sau khi launcher báo hoàn tất.

**Gỡ:** đóng game, mở Thiết lập và dùng chức năng gỡ mod. Launcher quản lý những file thuộc bộ cài của mình và khôi phục file có bản sao lưu.

## Khi gặp lỗi

| Hiện tượng | Việc nên kiểm tra |
| --- | --- |
| Không nhận thư mục game | Chọn thư mục chứa trực tiếp REPO.exe và REPO_Data. |
| Đã cập nhật nhưng vẫn thấy bản cũ | Đóng hẳn game, chạy EXE mới, cài lại bằng RESET rồi mở game. |
| F4/F5 không mở menu | Kiểm tra cài đặt đã hoàn tất và có trùng phím với mod khác không. |
| Chữ trong menu bị cắt | Gửi ảnh, độ phân giải và mức phóng to giao diện trong Issue. |
